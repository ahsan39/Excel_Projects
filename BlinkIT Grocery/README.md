# 🛒 BlinkIT Grocery Sales Analysis

---

# 📌 Project Overview

This project focuses on analyzing BlinkIT grocery sales data to uncover business insights related to sales performance, customer preferences, outlet efficiency, and product trends.

The analysis was performed using **Excel**, **SQL**, **Python**, and **Power BI** to transform raw grocery sales data into interactive business intelligence dashboards and analytical reports.

---

# 🎯 Project Objectives

- Analyze overall sales performance across different outlet types and locations
- Identify top-performing product categories and outlet segments
- Track customer rating trends and item visibility impact on sales
- Build KPI-driven dashboards for business decision-making
- Perform data cleaning, transformation, and exploratory data analysis

---

# 📊 Dataset Information

The dataset contains grocery sales transaction data including:

- Item Type
- Outlet Type
- Outlet Size
- Outlet Location
- Sales
- Ratings
- Item Visibility
- Item Weight
- Fat Content
- Establishment Year

### Dataset Size

- **8,523 Records**
- **13 Columns**

# 🔍 Analytical Workflow

## 1️⃣ Data Cleaning

- Removed inconsistencies and null values
- Standardized categorical values
- Validated sales and rating fields

---

## 2️⃣ Exploratory Data Analysis (EDA)

Performed analysis on:

- Product categories
- Outlet performance
- Customer ratings
- Sales distribution
- Outlet establishment trends

---

## 3️⃣ SQL Analysis

Developed SQL queries for:

- Sales aggregation
- Outlet-wise performance
- Product segmentation
- KPI calculations

---

## 4️⃣ Dashboard Development

Built interactive Power BI dashboards with:

- KPI Cards
- Slicers & Filters
- Category-wise analysis
- Outlet performance visualizations
- Trend analysis charts

---

# 📌 Key Insights

- Supermarket Type outlets generated the highest sales contribution
- Tier-based outlet locations showed clear sales performance differences
- Certain item categories consistently outperformed others in revenue generation
- Customer ratings remained stable across multiple outlet types
- Outlet establishment year showed correlation with sales performance
